E-WALLET - Finance Management App

*Overview
OALET is a personal finance management application designed to help users easily track and manage their money. The app provides a clean, intuitive interface for monitoring balances, transactions, savings, and financial activities.

*Key Features
Dashboard:
-Personalized welcome message
-Quick overview of available balance
-VISA card information display

Transaction Management:
-Send money functionality
-Request payments option
-View all transactions
-Recent activity tracking (subscriptions, purchases)

Financial Insights:
-Income vs. expenses visualization
-Monthly savings tracking with percentage comparisons
-Historical income/expense charts
-Payment history with dates and amounts

User Experience:
-Clean, card-based UI design
-Quick access to frequent contacts
-Time-based transaction filtering (Today view)

*Target Users
-Individuals wanting better control over their personal finances
-Users who need to track subscriptions and regular payments
-People who frequently send/receive money digitally
